    In German, a date like 19-09-2025 is read in the following standard way:
    
    \[
        \text{day (ordinal) + month + year}
    \]
    
    19-09-2025 is read as:
    
    \[
        \textit{neunzehnter September zweitausendfünfundzwanzig}
    \]
    
    In full sentence form:
    
    \[
        \textit{am neunzehnten September zweitausendfünfundzwanzig}
    \]
    
    Explanation:
    \begin{itemize}
        \item 19 → \textit{neunzehnter} (ordinal form)
        \item September → month name
        \item 2025 → \textit{zweitausendfünfundzwanzig}
    \end{itemize}
    
    Important:
    When using "am" (on the), the ordinal takes Dative case:
    \[
        \textit{am neunzehnten September}
    \]
